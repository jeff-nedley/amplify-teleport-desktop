AmpliFi Teleport for Desktop

This installer sets up the unofficial AmpliFi Teleport desktop client on your Mac — the same setup flow as the Windows installer.

  • Installs AmpliFi Teleport for Desktop into Applications
  • Detects whether WireGuard command-line tools are present
  • If WireGuard is missing, installs it silently via Homebrew (wireguard-tools + bash)
  • Sets up a one-time privilege helper so the app will not ask for your password on Connect/Disconnect later
  • Launches the app when setup finishes

Administrator privileges are required once for this installer (equivalent to the Windows UAC prompt). An internet connection is needed if WireGuard must be downloaded.
